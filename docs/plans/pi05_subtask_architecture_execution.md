### E0 原路径兼容与权重核验

- 依赖：P01–P04；扩展完成后重复受影响的兼容检查。
- 输入：固定 probe，不绑定 shoes 或其他具体任务。

- 通过：差异符合预先声明的等价性合同；未解释差异阻止后续结果解释。
- 边界：零样本文本流畅度不是代码正确性的替代；语言退化的原因须排除接口与权重错误后再分析。

### E1 结构正确性

来源：原调研 §14、N02；先用构造 token、固定张量和微型模型。

| 验证项 | 测试关系 | 依赖 |
|---|---|---|
| 未来目标隔离 | 改较晚目标，较早 logits 不变 | P06–P08 |
| CE shift | 条件末位→首 token；前一目标位置→EOS | P08 |
| masked hole | 缺相机和 padding 不误取首词 hidden state | P09 |
| 位置 | 物理取值索引与有效 token 逻辑位置分离 | P09 |
| 独立 EOS | batch 中不同结束时刻均正确处理 | P09 |
| 无效区 | 修改 padding ID 不改有效输出、不产生 NaN | P06/P09 |
| 梯度 | CE 与动作监督到达约定参数，无意外 no_grad/detach | P08/P10 |
| 归约 | 零监督、变长及 DDP 分片符合固定合同 | P08/P12 |
| 低层隔离 | 固定 o/s/噪声，只改 g，低层输出不变 | P10/P11 |
| 单次生成 | 返回 s 与实际动作条件一致，无二次生成 | P11 |
| 保存恢复 | 同输入同噪声输出及预期训练状态一致 | P12 |
